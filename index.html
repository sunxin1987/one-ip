安卓安装（APK 说明）

  

    
先说清：原项目 One IP 本身是一个网页应用（React + Cloudflare Workers），官方从未发布过原生 APK；这个空间也是静态网页，无法在这里直接生成一个已签名的原生安装包。下面是等效的「装成 App」方法，装完桌面图标点开就是全屏版 One IP，和 APK 的使用感一致，且自动跟随本页更新。

    

      
方法一 · Chrome「安装应用」（推荐）
安卓 Chrome 打开本页 → 右上角菜单 ⋮ →「添加到主屏幕 / 安装应用」→ 确认。桌面会出现 One IP 图标，全屏打开、无浏览器边框。

      
方法二 · 想要真正的 .apk 文件
把本页（或原版 ip.huzhihui.com）用 PWA 打包服务生成：打开 PWABuilder.com → 输入网址 → 选择 Android 包 → 下载生成的 APK / AAB 后在手机上安装（需允许「安装未知应用」）。这是微软官方的 PWA 转 APK 工具，生成的包本质是套壳打开网页。

      
方法三 · 自托管原版
原项目支持一键部署到 Cloudflare 或 Docker 自托管（docker compose up -d --build，端口 8080），部署后同样可以用方法一装到手机。源码与部署文档见 GitHub 仓库。
